# 🏥 Medical Data Analysis Pipeline Using Google Cloud BigQuery and SQL

## 📌 Introduction
The Medical Data Analysis project focuses on cleaning, transforming, validating, and analyzing medical data using Google Cloud BigQuery and SQL. An interactive dashboard was developed using Looker Studio to visualize patient demographics, medical conditions, hospital admissions, billing amounts, and length of hospital stay.

## 🎯 Objectives
- Clean and transform raw medical data.
- Standardize gender values and handle data quality issues.
- Analyze patient demographics and medical conditions.
- Evaluate hospital admissions and billing patterns.
- Calculate average billing amounts and length of hospital stay.
- Validate cleaned data using SQL queries.
- Build an interactive healthcare dashboard.
